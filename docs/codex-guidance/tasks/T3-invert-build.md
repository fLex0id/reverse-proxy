# T3. Инверсия сборки без изменения поведения

**Тип:** рефакторинг с механическим доказательством эквивалентности.
**База:** тег `task-2-accepted` (или `task-0-accepted`, если T2 не выдавался). Ветка `task/3-invert-build`.
**Читать:** `AGENTS.md`, `TECHNICAL-DETAILS.md` §2–§4, `DECISIONS.md`.

## Цель

Сделать `src/` источником истины, а `rp.sh` — сгенерированным файлом `dist/rp.sh`, **побайтно равным эталону** (с точностью до строки версии).

## Сделать

1. Разрезать `rp.sh` на файлы в `src/` по границам, которые уже есть в тексте (встроенные `rp.py`, `transaction.py`, `migration.py`; блоки Bash). Порядок модулей — явный файл `src/modules.list`, без шаблонов подстановки.
2. `tools/build.py` (только стандартная библиотека): склеивает модули, подставляет версию из `VERSION`, детерминирован (LF, без меток времени, фиксированная сортировка). Падает, если делимитер вложения встречается внутри вложения.
3. Отдельно выкладывать каждое вложение файлом в `build/` для `shellcheck`, `bash -n`, `pyflakes`. Адаптировать `tools/static-check.py` и `tools/embed-*.py`, **не ослабляя** проверок.
4. CI: результат сборки равен закоммиченному `dist/rp.sh`.
5. `tests/golden/`: для набора фикстур `rp.conf` (15 непустых подмножеств транспортов; ≥ 2 SNI; ≥ 2 DNS; 0 и 3 клиента; режимы авто и закрепления) сохранить вывод генераторов из **эталона** и сравнивать побайтно.
6. Тест поверхности CLI: список команд из `main` и вывод `rp help`.
7. Хэш каждого модуля записывается в `build/MODULES.sha256`.

## Ворота (все обязательны)

- `sha256(dist/rp.sh)` после замены строки версии на исходную **равен** эталону. Два прогона сборки дают одинаковый хэш.
- 155+ тестов и `static-check.py` проходят; число тестов не уменьшилось.
- Золотые файлы и тест CLI проходят на эталоне и на новой сборке одинаково.
- `git diff` не содержит изменений логики: любой diff в модулях — только перенос.

## Нельзя

Менять логику, имена функций, порядок кода внутри модулей, тайминги. Добавлять команды CLI. Трогать `reports/results/`. Выпускать релиз.

## Остановка

Если побайтное равенство недостижимо без правки логики — остановиться и описать расхождение (какие байты, почему).
